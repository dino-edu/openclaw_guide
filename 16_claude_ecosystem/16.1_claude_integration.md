## 16.1 Kết nối mô hình Claude & Tích hợp hệ sinh thái MCP

Mục này làm rõ cách thức OpenClaw kết nối với gia đình mô hình Claude của Anthropic, cũng như cách thức thông qua giao thức MCP (Model Context Protocol) để đưa các công cụ và nguồn dữ liệu bên ngoài vào Agent. Cấu hình cơ sở cho nhà cung cấp mô hình đã được trình bày tại [Mục 4.2](../04_config_models/4.2_provider_access.md); lựa chọn mô hình và chuỗi Fallback xem tại [Mục 4.3](../04_config_models/4.3_model_selection.md) và [Mục 4.4](../04_config_models/4.4_failover.md). Trên nền tảng đó, mục này tập trung vào các điểm tích hợp đặc thù của hệ sinh thái Claude.

### 16.1.1 Toàn cảnh gia đình mô hình Claude

Các dòng mô hình Claude của Anthropic phân chia theo năng lực và chi phí thành các chuỗi chính:

| Dòng mô hình | Định vị | Cửa sổ ngữ cảnh (Phía OpenClaw) | Ghi chú kỹ thuật |
|---|---|---|---|
| **Haiku 4.5** | Độ trễ thấp, chi phí siêu rẻ | 200K | Phù hợp kịch bản tần suất cao; hỗ trợ Extended Thinking (không phải Adaptive) |
| **Sonnet 4.6** | Cân bằng hiệu năng / chi phí | 1M (Yêu cầu bật `params.context1m: true`) | OpenClaw mặc định chạy chế độ Adaptive Thinking |
| **Opus 4.6** | Năng lực suy luận chuyên sâu | 1M (Yêu cầu bật `params.context1m: true`) | OpenClaw mặc định chạy chế độ Adaptive Thinking |
| **Sonnet 5** | Thế hệ Sonnet tiền nhiệm (Ra mắt 2026-06-30) | 1M bật sẵn mặc định | Adaptive Thinking mặc định bật; không hỗ trợ Extended Thinking thủ công |
| **Sonnet 5.5** | Model Sonnet chủ lực hiện hành (`claude-sonnet-5-5`) | 1M Context, 128K Output | Adaptive Thinking mặc định bật; tắt suy nghĩ trước khi hành động bằng `between_tools` |
| **Opus 4.7 / 4.8** | Các thế hệ Opus suy luận sâu | 1M Context bật sẵn | Mặc định `effort=high`, chi tiết thinking căn cứ theo catalog |
| **Opus 5 / 5.5** | Model Opus chủ lực hiện hành (`claude-opus-5-5`) | 1M Context, 128K Output | Adaptive Thinking thường trực (không thể tắt); khuyến nghị làm điểm khởi đầu cho tác vụ khó |
| **Fable 5 / 5.1** | Dòng mô hình năng lực đỉnh cao | 1M Context, 128K Output | Adaptive Thinking thường trực; phục vụ các bài toán phức tạp nhất |

> **Lưu ý**: Tên phiên bản cụ thể, độ dài cửa sổ ngữ cảnh và giá cước có thể thay đổi theo lộ trình của Anthropic, vui lòng đối soát trực tiếp tại [Tài liệu chính thức của Anthropic](https://platform.claude.com/docs/en/models/overview).

### 16.1.2 Cấu hình Claude trong OpenClaw

OpenClaw sử dụng định dạng chuẩn `provider/model`. Đối với provider Anthropic tích hợp sẵn, sau khi hoàn tất xác thực qua `openclaw onboard`, bạn chỉ cần khai báo trong `agents.defaults.model`:

```jsonc
{
  agents: {
    defaults: {
      model: {
        primary: "anthropic/claude-sonnet-4-6",
        fallbacks: [
          "<provider/low-cost-model>",
        ],
      },
    },
  },
}
```

Nếu chạy qua máy chủ Proxy tự dựng của doanh nghiệp:

```jsonc
{
  models: {
    providers: {
      anthropic: {
        apiKey: "${ANTHROPIC_API_KEY}",
        baseUrl: "https://my-proxy.internal/anthropic/v1",
        api: "anthropic-messages",
        models: [{ id: "claude-sonnet-4-6", name: "Claude Sonnet 4.6" }],
      },
    },
  },
}
```

Nếu gọi Claude qua Google Cloud Agent Platform (trước đây là Vertex AI), hãy dùng định danh `anthropic-vertex/claude-sonnet-4-6` và nạp chứng thư qua GCP Service Account / Application Default Credentials.

### 16.1.3 Các năng lực đặc thù của Claude & Điểm lưu ý

- **Cửa sổ ngữ cảnh mở rộng (1M Context)**: Trên Sonnet 4.6 và Opus 4.6, để dùng trọn 1M Token qua đường Direct API, bạn cần khai báo tường minh `params.context1m: true` và tài khoản phải đủ điều kiện.
- **Tư duy tự thích ứng (Adaptive Thinking)**: Dòng Claude 4.6 trở lên trong OpenClaw mặc định vận hành ở chế độ Adaptive Thinking. Bạn có thể kiểm soát việc hiển thị quá trình suy nghĩ qua tham số `display` (`"summarized"` hoặc `"omitted"`). Toàn bộ Thinking Token đều tính vào lượng tiêu thụ API.
- **Tương thích hoàn hảo với Tool Calling**: Claude trả về yêu cầu gọi công cụ dưới dạng JSON có cấu trúc chặt chẽ, được Agent Runtime của OpenClaw tự động bóc tách và phân phối thực thi. Các công cụ nhạy cảm đòi hỏi con người phê duyệt vẫn tuân thủ cơ chế cổng HITL của Gateway.

### 16.1.4 Tích hợp Máy chủ MCP (Model Context Protocol)

MCP (Model Context Protocol) là giao thức chuẩn mở do Anthropic khởi xướng, nhằm chuẩn hóa việc giao tiếp giữa mô hình AI với các nguồn dữ liệu và công cụ bên ngoài. OpenClaw tích hợp sẵn MCP Client, cho phép Agent kết nối tới các MCP Server để đọc file hệ thống, truy vấn cơ sở dữ liệu hoặc thao tác trên GitHub.

#### Các phương thức kết nối MCP trong OpenClaw

| Phương thức | Kênh truyền thông | Kịch bản áp dụng |
|---|---|---|
| **stdio** | Luồng chuẩn Input/Output | Máy chủ MCP chạy cục bộ trên máy (như File System, Git) |
| **HTTP (Streamable HTTP)** | HTTP Request/Response có hỗ trợ streaming | Dịch vụ MCP từ xa hiện đại, API Gateway, Cloud Services |
| **SSE (Tương thích cũ)** | Server-Sent Events | Tương thích các MCP server cũ; dịch vụ mới ưu tiên Streamable HTTP |

#### Ví dụ cấu hình MCP Server

```jsonc
{
  // Các máy chủ MCP do OpenClaw quản lý nằm tại khối cấp cao nhất mcp.servers
  mcp: {
    servers: {
      // Máy chủ MCP chính thức của GitHub (chạy qua stdio trong Docker)
      github: {
        command: "docker",
        args: [
          "run",
          "-i",
          "--rm",
          "-e",
          "GITHUB_PERSONAL_ACCESS_TOKEN",
          "ghcr.io/github/github-mcp-server",
        ],
        env: {
          GITHUB_PERSONAL_ACCESS_TOKEN: "${GITHUB_PAT}",
        },
      },
      // Máy chủ MCP từ xa (chạy qua Streamable HTTP)
      "custom-api": {
        url: "https://api-gateway.internal/mcp",
        transport: "streamable-http",
        headers: {
          Authorization: "Bearer ${CUSTOM_API_TOKEN}",
        },
      },
    },
  },
}
```

#### Mối quan hệ giữa Công cụ MCP và Công cụ tích hợp sẵn

Công cụ tích hợp sẵn của OpenClaw (File, Shell, Browser...) được quản trị qua Tool Policy (xem [Mục 5.2](../05_tools_skills/5.2_tool_policy.md)), tồn tại **song song** với các công cụ do MCP Server cung cấp:
- **Công cụ tích hợp sẵn**: Thực thi trực tiếp bởi Agent Runtime, chịu sự ràng buộc của Tool Policy và Sandbox, độ trễ thấp nhất.
- **Công cụ MCP**: Giao tiếp xuyên tiến trình qua giao thức MCP, phù hợp để tích hợp dịch vụ bên thứ ba hoặc API doanh nghiệp.

Cả hai nhóm công cụ đều hiển thị đồng thời trong danh mục công cụ khả dụng của Agent, và mô hình AI sẽ tự quyết định nên gọi công cụ nào tùy theo ngữ cảnh.

Trong môi trường sản xuất, việc kết hợp Claude với các nhà cung cấp khác sẽ giúp nâng cao tính sẵn sàng và tối ưu chi phí:

| Chiến lược | Mô hình chính (Primary) | Mô hình dự phòng (Fallback) | Kịch bản tối ưu |
|---|---|---|---|
| **Claude chủ lực** | `anthropic/claude-sonnet-4-6` | `openai/gpt-5.5` | Ưu tiên tối đa chất lượng suy luận |
| **Chi phí tối ưu** | Model độ trễ thấp trong danh mục | `anthropic/claude-sonnet-4-6` | Tải cao, tiết kiệm chi phí |
| **Dự phòng xuyên hạ tầng** | `anthropic/claude-sonnet-4-6` | `anthropic-vertex/claude-sonnet-4-6` | Cùng model nhưng chạy trên hạ tầng đám mây khác nhau |
